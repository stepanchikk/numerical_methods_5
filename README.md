# Лабораторна робота №5 — варіант 7

Чисельне диференціювання та інтегрування. Python 3.10+.
Чисельні обчислення використовують стандартну бібліотеку; для графіків потрібен matplotlib.

## Запуск у PyCharm

1. Відкрити цю папку через **File → Open**.
2. У **Settings → Project → Python Interpreter** вибрати Python 3.10 або новіший; можна створити Virtualenv.
3. У терміналі PyCharm виконати `python -m pip install -r requirements.txt`.
4. Відкрити `main.py` і натиснути **Run**.

У терміналі: `python3 main.py`. Для показу графіків у вікнах: `python3 main.py --show-plots`.
У PyCharm також можна додати `--show-plots` до **Run → Edit Configurations → Parameters**.
Перевірки: `python3 -m unittest discover -s tests -v`.
Результати автоматично записуються у `output/results.json` та `output/results.txt`.

## Вхідні дані

x = (0.231, 0.881, 1.531, 2.181, 2.831)

y = (-2.748, -3.225, -3.898, -5.908, -6.506), h = 0.65.

Ньютон: x=0.231 і 2.2; Стірлінґ: x=1.531; прості формули: x=1.531 і 2.181.

Інтеграл від 2 до 2.5 функції (x+2)/(x²−x+1).
Середні прямокутники: ε=0.01; трапеції: ε=0.001; Сімпсон: ε=0.0001.
Початкові n=5, 5, 6, далі подвоєння. Повертається значення на дрібнішій сітці;
оцінка Рунге: |I₂ₙ−Iₙ|/(2ᵖ−1), p=2, 2, 4 відповідно.

Округлення похідних до тисячних відповідає методичному зразку, але не є гарантією
похибки 0.001: аналітичний вигляд табличної функції невідомий.
Ньютон і Стірлінґ на всіх п'яти вузлах диференціюють один многочлен четвертого степеня.

## Графіки

Після запуску `main.py` автоматично створюються:

- `output/plots/interpolation.png` — табличні точки, многочлен Ньютона четвертого степеня та дотична в центральному вузлі. Крива показує інтерполяційний многочлен, а не невідому аналітичну функцію.
- `output/plots/integration_methods.png` — три панелі: середні прямокутники (n=5), трапеції (n=5) та локальні параболи Сімпсона (n=6) разом із підінтегральною функцією. Показано початкові сітки; кінцеві сітки Рунге наведені в результатах.

Графіки включено у DOCX; їхня побудова реалізована в `src/plotting.py`.
